# Joel Chaple's Computational and Applied Astrophysics/Mathematics
## Overview
This repository contains personal projects I've developed to pratice and learn more about computational techniques in physics, math, and similar fields. Initially this repository focused on orbital mechanics within a two body system with the complexity of the methods being used increasing over time as skills are developed. Now the plan is to keep commiting and working on any related projects as I go through roughly the next seven years of my education or more.  
## Contents
- ### Orbital Mechanics:
  Simulations and calculations regarding planetary and stellar orbit, celestial dynamics, and trajectory analysis
- ### Numerical Analysis:
  Algorithims for different mathematical contexts including:
  - Bisection Method - Accurately approximates the roots of functions within the right conditions 
## Purpose
- Write real-life problems into accurate working code
- Publicize personal code for reproducibility
- Expand from simple ideas to complex algorithims
